UNIDADE CURRICULAR – LÓGICA DE PROGRAMAÇÃO (Questões 01 a 10)
QUESTÃO 01
Um programador está desenvolvendo um módulo de automação para uma estufa agrícola em linguagem C. Para que o programa possa ser compilado e executado pelo sistema operacional, é obrigatório definir o ponto de entrada principal do código.

Qual é a assinatura correta dessa função principal em C?
QUESTÃO 02
Em um sistema de controle de acervo de uma biblioteca em C, o operador precisa digitar a quantidade de livros a serem emprestados (um valor inteiro) via teclado.

Qual instrução realiza a leitura correta e salva o valor na variável quantidade?
QUESTÃO 03
Em um algoritmo para gerenciar a distribuição de estudantes em laboratórios de informática, aplicou-se a seguinte operação aritmética em C: 
int resultado = 38 % 6;
Qual será o valor final armazenado na variável resultado?
QUESTÃO 04
Um sistema de monitoramento para uma câmara fria utiliza um código em C para validar a temperatura atual de armazenamento. Considere o trecho abaixo: 
int temp = -2;
if (temp >= 0) {
    printf("Temperatura Ok");
} else {
    printf("Alerta de Congelamento");
}
Qual mensagem será exibida na tela?
QUESTÃO 05
Um sistema de avaliação acadêmica de um curso de robótica classifica o desempenho dos alunos com base na nota final obtida. Analise o trecho a seguir: 
int nota = 85;
if (nota >= 90) {
    printf("CONCEITO A");
} else if (nota >= 70) {
    printf("CONCEITO B");
} else {
    printf("CONCEITO C");
}
Qual conceito será atribuído e impresso na tela?
QUESTÃO 06
O sistema de controle de acesso de uma academia só libera a catraca se o aluno tiver idade maior ou igual a 18 anos E atestado médico válido (representado por atestado == 1).

Considerando idade = 22 e atestado = 1, qual das expressões condicionais em C retornará verdadeiro (1)?
QUESTÃO 07
Examine o laço de repetição for abaixo, projetado para emitir etiquetas de lote de produção em uma impressora industrial: 
int i;
for (i = 5; i <= 25; i += 5) {
    printf("Etiqueta lote %d\n", i);
}
Quantas vezes a mensagem "Etiqueta lote" será impressa na tela?
QUESTÃO 08
Analise a estrutura de repetição while em um algoritmo que controla a drenagem automática do reservatório de combustível de um gerador: 
int combustivel = 40;
while (combustivel > 0) {
    combustivel -= 12;
}
Qual será o valor final acumulado na variável combustivel após o término da execução do laço?
QUESTÃO 09
Um sensor pneumático monitora a despressurização de um pistão industrial (variável pressao) durante um ciclo de trabalho em C: 
int pressao = 25;
while (pressao > 0) {
    pressao -= 6;
}
Qual será o valor exato armazenado na variável pressao no momento em que o laço encerra sua execução?
QUESTÃO 10
Considere o seguinte algoritmo em C que contabiliza a quantidade de números pares dentro de uma sequência de amostragem: 
int i, pares = 0;
for (i = 1; i <= 8; i++) {
    if (i % 2 == 0) {
        pares++;
    }
}
Qual será o valor final acumulado na variável pares ao término do laço?
